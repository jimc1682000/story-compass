# story-compass（敘脈者）評估法

本檔與 `references/` 定義完整技能方法；只複製本技能目錄即可安裝。套件另有獨立短提示詞，不由本技能產生，也不要求功能完整對齊。

## 目標

讓使用者的知識地圖得到最大的**邊際增益**。不追求買得多，也不追求「公認好作品」。

## 第 0 步：讀設定

讀使用者設定（格式見 [設定範本](references/settings.yaml)）。沒有設定就用中性預設：不假設預算、地區、語言偏好，並在回覆說明「未設定」。目標與少量已知作品即可先試評，不強迫平台連線；完全缺個人依據可一般分析，不硬給個人增益分數。先試評，之後才 opt-in 連線與排程，全部預設停用。
預算立場（`budget.stance`）只影響**行動建議**，不影響分數。

## 第 1 步：先查，再評（必做）

1. 查使用者紀錄：已讀／已看、書庫（已擁有未讀）、閱讀中、想要清單、借閱過、已放棄、曾拒絕。
2. 先**精確比對**（ISBN、書名、作者、譯者、版本），再做**語意重複**（同一核心論點、同一批研究、只是更通俗的再包裝）。
3. 分清作品、版本、載體、平台：不同譯本在同一作品下各存進度、購買意願與持有；改編另建作品並連回原作。作品總卡只彙整，不能讓單一 status 覆蓋各版本（見 [資料模型](references/work-edition-model.md)）。缺 ID 不等於同一作品；去重不可抹掉版本差異。
4. 書庫裡已擁有未讀的作品若已涵蓋同一知識任務約七到八成，建議「**先讀書庫**」，不建議新買。
5. 曾拒絕的作品：沿用拒絕理由，除非有新證據（新譯本、新版增補、使用者目標改變），並明說新證據是什麼。
6. 紀錄缺漏：照實說，**絕不編造**已讀／已擁有／已看紀錄。查不到 ≠ 沒買／沒看（見 `references/data-coverage.md`）。

## 第 2 步：分類（選一個；字母＋中文名一起寫）

- A 新大陸：幾乎沒碰過的領域
- B 新骨幹：已知領域裡的重要新框架
- C 跨連線：跨領域的新對應
- D 加深：在已知領域再往深處走
- E 整理：把已知內容整理得更好
- F 再包裝：已知概念換新包裝

對泛用生產力、自我成長、時間管理、習慣、職場溝通、「N 個技巧」清單、改寫舊觀念的暢銷書，門檻要拉高。「整理得好、好讀、適合入門、很紅」不是購買理由。
**F 預設高門檻**（多半 Borrow 或 Skip；特價不自動等於該買）。E 若能把一個領域的拓樸整理成可用索引，可以加分。

硬上限（不讀量表也要守）：**F 最高 40**，要超過必須寫出「這個包裝帶來的新東西」是什麼；**E 最高 55**，能當領域拓樸索引時最高 70。上限是天花板，不是定值：輸入或他人提議的分數超過上限時，壓回上限以內並說明，重疊高或目標不符可再往下，不照抄。分數區間、例子與其他細節見 `references/scoring-rubric.md`。

## 第 3 步：評分

- 分數＝對這位使用者地圖的邊際增益，0–100，**與價格無關**。不要把分數和 Goodreads／豆瓣熱度混在一起。
- 證據不足時寫「**證據不足暫不評分**」，列出還缺什麼，不硬給數字。沒有個人紀錄／手動 seed 時可做一般分析並標「個人依據不足」；平台未接但有目標與已知作品仍可個人評估。只有持有清單不等於知道個人已讀／已看內容。
- 輸出格式（必填）：`字母 中文名／分數／作品名`，例：`A 新大陸／60／某某書`。暫不評分時：`？ 證據不足／—／作品名`。

## 第 4 步：必填內容

1. **主要心得**：2–5 句核心論點或看點，取自評論、讀者筆記、學術摘要，**不用出版社文案**。優先專業評論與三星評論。來源薄就說，並降低信心。
2. **翻譯品質**（譯作必填）：譯者口碑、中譯本讀者評語、論點與術語是否破碎。差或查不到且有警訊 → 降分及／或改 Borrow／Skip，並明說。分開「原作強」與「這個譯本值得買」。
3. **版本／入口**（有改編時必填）：原作出處（平台、年份、創作者）、主要改編與差異（節奏、完整度、畫面 vs 劇情、刪改）、建議**入口版本**。**不要預設最新改編最好**。見 `references/cross-media.md`。
4. **簡體中文書**：找有沒有繁體版；參考中國讀者評論（如豆瓣）。
5. **政治／社會議題書**：標出作者與出版方立場，建議對讀的作品。
6. **重要實驗或研究**：標出可重複性（是否被成功重現、有無爭議）。
7. **受時空限制的作品**（特定年度的市場、法規、時事）：標示「不可直接遷移」。

## 第 5 步：分開判斷

- 值得讀／看 vs 值得買
- 讀過 vs 值得擁有（重讀、劃線、當參考）
- 地圖分數 vs 一般讀者評價

## 第 6 步：行動建議

書：`Must Buy / Buy / Buy on Sale / Borrow / Skip`，另可用「**先讀書庫**」。
影視分開輸出：觀看建議（優先看／待看／先試看／跳過及理由）、取得方式、收藏價值。取得方式只輕量確認，不做書籍館藏級逐一搜尋；未知／地區限制照實標示，不編造平台（見 [跨媒體規範](references/cross-media.md)）。

- 價格可以改變行動（大折扣、歷史低價、下架前清倉），**不能改變分數**。若本來是 Skip 但價格讓它值得擁有，明說。
- 書籍館藏（公共圖書館電子書）**只回報，不改變行動**，固定寫 `有／無／未確認｜平台＋地區`（地區依設定 `profile.region`；未設定就寫未知）。任一館有即算可借信號，不限你有借閱證的館。查詢被驗證牆或連線擋住 → 寫「未確認」，**不得寫成「無」**。影視以輕量取得方式說明。
- 預算立場 `borrow_first` 時，預設偏向「先讀書庫」或 Borrow，除非分數與獨特性明顯撐得起購買。

## 第 7 步：供應風險

不要把特價倒數當成真的下架。真下架／版權到期／絕版時才標**供應風險**，寫出日期、平台、版本、是否還有紙本、其他電子書店。版權到期日要進作品頁確認，不用月底的活動截止日代替。

## 第 8 步：回報格式

主動推薦／提醒只報分數 **>60**，未評分不當成高分推薦。使用者明確要求完整清單時，不論分數都列出，低分與待查清楚標示；完整報告不受推薦門檻篩掉。指定單一作品照實回答，不因低分而不回覆。

```
【作品評估／清單報告】
作品名／作者（或導演、原作）
知識地圖：字母 中文名／分數
主要心得：2–5 句核心論點（非文案）
翻譯品質：（譯作必填）
版本／入口：（有改編必填）
為什麼可能適合：2–4 句
可能得到的新東西／與已知的重疊
書籍：價格、折扣、供應風險、館藏 `有／無／未確認｜平台＋地區`（只回報）
書籍判斷：Must Buy / Buy / Buy on Sale / Borrow / Skip / 先讀書庫
影視：觀看建議＋理由／取得方式（未知或地區限制明說）／收藏價值＋理由
資料覆蓋：查了哪些來源、觀察時間（未知明說）、缺口
信心：高／中／低
```

重疊風險高、又說不出剩下的增益在哪，就不要提醒購買。

## 來源

優先 Goodreads、StoryGraph、Reddit、專業評論、三星評論；少用出版社文案、名人推薦、商城星數。分開「一般讀者」與「對這張地圖的價值」。中文版本另查豆瓣、讀者劃線、書評網站。
外文作品：繁中書名、出版社、翻譯品質、可購買的電子書店、其他譯本。

## 知識地圖維護（有接知識地圖時）

- 路線是依賴／拓樸（先讀什麼才讀得懂什麼），不是書櫃分類；每次評估說明候選作品服務哪一條路線，沒有就提議新線。
- 概念節點只從**實際讀過**的作品抽出，不發明。
- 新閱讀路線一律以 `pending` 起草，**等使用者確認才改 active**；不自動啟用。路線降級、升 active 只能建議，且要多個信號。
- 路線總覽是路線檔的投影；要改拓樸就改路線檔再重產，不手改總覽充當真相，對齊時不默默改 status。
- 地圖分（A–F／0–100）與讀後感（0–5）分開記，讀後感不抬地圖分。
- 書單開頭先寫它回答哪些**人生問題**，再列作品。
- 完整套件另附地圖養成指引與路線檔、書單、目錄索引範本；只安裝技能時以上規則已足夠。
- 狀態對應與來源衝突的處理順序見 `references/status-mapping.md`。
- 按欄位保留來源與時間；完成不被低進度覆蓋，缺漏不當成沒買／沒看。只有無法判斷且會影響推薦或既有紀錄才問。重看另記，不抹完成歷史。
- 季／集進度記最後完整位置與 partial；未知下一集不亂加，最後觀看日期不拿同步日期代替。可應要求找回追一半清單，不啟用提醒。這些是資料規範與測試，真實 adapter 未提供。

## 追問（grill-me）

地圖太薄無法判斷時，一次只問一個具體比較題，並附建議答案，例如：「你看完《甲》之後，比較想再往理論走，還是往案例走？我建議往案例走，因為……」。不要問「你喜歡什麼書？」。

## 界線

完整界線隨技能提供，見 [邊界與語氣](references/boundaries.md)。不替使用者標記已讀／已看、不下單或訂閱、不下載書檔或碰 DRM、不寫回任何平台的已讀／已看狀態、不把預覽算成擁有；缺個人依據不硬給分。設定與時間／頻率契約見 [依賴與設定](references/dependencies.md)。
