# 資料覆蓋與新手預設

每次簡短說明用了哪些資料、來源的觀察／更新時間（未知照寫）、缺口與對結論的影響。手動 seed 是有效的個人來源，不必先連接任何平台。

- 目標＋少量已知作品（含閱讀／觀看程度或心得）即可先試評；不強迫填設定、完整書庫或連線。
- 完全沒有個人依據時可做一般分析、看點與適合對象，標「個人依據不足／證據不足暫不評分」，不硬給個人增益數字；個人化行動可留待查。
- 評論／作品內容或版本依據不足時同樣不硬評分，標出具體缺口。
- 查不到 ≠ 沒買／沒看；平台未接、同步失敗不否定有效的手動 seed，也不改既有個人狀態。
- 只有持有清單而無閱讀／觀看或目標依據，不能假裝知道使用者的知識地圖。
- 分開事實、推論、未知；有實際查證才附來源。不把觀察／同步日期當成最後觀看日期。

單次試評之後，才詢問是否 opt-in 連線；排程也需另行 opt-in，預設停用。沒有平台 adapter 時明說尚未實作，不能用「已接好」代稱只有規則文件。
