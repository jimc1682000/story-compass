# 跨媒體與影視輸出

支援書、漫畫、動畫、電影、影集的評估規範。資料格式已定義，真實平台 adapter、連線與模型輸出品質仍未實測。

## 原作、改編與入口

原作與每個改編各有作品 id，以 adaptation_of 連回原作。列原作出處（創作者、年份、平台；未知明說），說明主要改編的節奏、完整度、刪改、畫面／敘事差異，再選適合目標的入口；不要預設最新改編最好。不同譯本留在原作品的 editions。

看過改編不代表讀過原作；比較原作多出的支線、內心描寫、結局或美學體驗，不把整份原作內容都算全新。來源薄就降低信心，不編造版本細節。

## 影視分三段輸出

| 段落 | 輸出 |
|---|---|
| 觀看建議 | 優先看 / 待看 / 先試看 / 跳過，必須附增益與重疊的具體理由；缺個人依據時標「一般分析」 |
| 取得方式 | 只輕量確認一個適用地區的合法入口或使用者已有管道；不逐一做書籍館藏級搜尋。未確認標未知，地區限制明說；有查才附平台、地區、來源與查核時間，不編造可看平台 |
| 收藏價值 | 高 / 低 / 未知及理由；分開是否值得重看、擁有或買實體，不能用「已看／已擁有」代替價值判斷 |

觀看建議預設傾向：81–100 優先看、61–80 待看、41–60 先試看、0–40 跳過；這是行動傾向，可依具體理由調整，不是平台 availability 的函式。價格只影響取得／購買行動，不改增益；不替使用者訂閱，也不自動建議為單一作品加訂平台。

書籍仍使用 Must Buy / Buy / Buy on Sale / Borrow / Skip 或先讀書庫；書籍館藏只回報，不改變評估行動。

## 連續作品

版本各自記 progress，各季另存獨立 state、最後完整集數與 partial_episode；版本摘要保留最後完整季集與 partial；首次完成與重看 run 分開。追看、暫停、棄追、完成不能互相推論；久未更新不自動棄追。下一集與日期規則見 [狀態規範](status-mapping.md)。找回追一半清單只在使用者提出時產生，沒有提醒器或排程實作。

## 主要心得來源

可參考專業影評、IMDb／Letterboxd 使用者長評、MyAnimeList／Bangumi（動畫）、豆瓣。這是查證方向，不是必接服務或來源優先序的變更；宣傳文案不能充當獨立心得。

遊戲、桌遊不在範圍內。本套件不提供片單同步 adapter。
