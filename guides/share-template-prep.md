# 分享範本準備指引（Grok Bot Share Template）

狀態：**指引草稿；未建立任何分享範本，也未實測範本機制**。

## 範本說明（乾淨版本，可直接用）

> story-compass（敘脈者）：用你自己的知識地圖判斷一部書、漫畫、動畫、電影或影集值不值得現在買、看、借或跳過。分數是「對你的邊際增益」，與價格無關。先問你的目標和幾部已知作品就能開始；書櫃、影視紀錄、例行任務都是選用，之後再接。它不會替你下單、訂閱、標記已讀／已看，也不下載書檔或碰 DRM。

## 要放進範本的技能

- `story-compass`（`skill/` 整個資料夾：`SKILL.md`＋`references/`）

只放這一個。不要另外拆小技能。

## 開始使用的流程

照 `guides/grok-bot-first-run.md`：目標與已知作品 → 試評一部 → 選用連線 → 選用例行任務。

## 包含／排除

| 包含 | 排除 |
|---|---|
| 角色描述（依 `ROLE.md` 改寫，無個人資料） | 擁有者的名字、帳號、信箱、倉庫名稱 |
| 核心技能與參考檔 | 擁有者的書庫、願望清單、閱讀路線、書單、借閱紀錄 |
| 空白設定與種子範本 | 擁有者的排程時間、時區、例行任務實際內容 |
| 首次設定流程 | 任何 token、主機名稱、內部網址、代理 ID |
| （可選）例行任務**說明文件** | **例行任務本身**（見下） |

## 例行任務的處理

- 如果範本機制**不能保證**例行任務在新使用者端是**停用**狀態，就**完全不要把例行任務放進範本**，只附 `guides/routines.md` 讓使用者自己建立。
- 目前**未確認**範本機制的行為 → 預設排除。
