# 連線指引：電子書平台書櫃（只讀清單；以 Kobo 為例）

| 項目 | 狀態 |
|---|---|
| 規則、欄位對應、排除條件 | 已定義（本檔、`skill/references/status-mapping.md`）；本檔以 Kobo 為例，其他電子書平台的清單匯出放 `data_sources.library_export` 套同一組規則 |
| 同步程式 | **本套件未附**。擁有者的私人環境有一個只讀清單的實作，未公開 |
| 用真實帳號實測 | 擁有者環境有；**本套件版本未實測** |

## 原則（不可協商）

1. **只讀清單中繼資料**：書名、作者、ISBN、閱讀狀態、完讀時間、願望清單價格。
2. **不下載書檔、不碰 DRM**。若你用的工具本身含下載或解除 DRM 的功能，必須在程式載入時就停用那些路徑，並在輸出前移除下載網址與內容金鑰類欄位。
3. **憑證只在你自己的機器**（檔案權限限本人），不進 Git、不進 log、不貼進對話。
4. **首次登入由你本人完成**（例如在 Kobo 的裝置啟用頁輸入啟用碼）；敘脈者不代為登入。
5. 使用非公開 API 可能違反服務條款；是否使用由你自行判斷。也可以改用**手動匯出清單**（見下）。

## 要讀哪些資料

| 來源 | 內容 |
|---|---|
| 書櫃同步端點（與官方閱讀器相同的清單端點） | 擁有的電子書／有聲書、閱讀狀態、完讀時間 |
| 願望清單端點 | 想要清單、價格 |

## 欄位對應與排除

- 狀態：`ReadyToRead`→未讀、`Reading`→閱讀中、`Finished`→已讀。
- 排除：預覽本（`Accessibility == "Preview"`）、書名含試讀／預覽／試閱、平台已封存（`IsRemoved`）可從該平台的活動清單排除，但不直接抹掉既有持有或完成歷史。
- 同版本的完成不被低進度覆蓋；完讀時間變新只列重讀候選，無法判斷且會影響紀錄時才問，保存回答；重讀另記。
- ISBN 只收檢查碼正確的 ISBN-13；專有編號另存，不混入 ISBN。
- 購買意願與持有分欄；已買不能自動抹掉想要其他版本的意願，同書名不同版本保留。

## 同步行為

- 總數以該來源所選匯出範圍核對；持有與讀過分開統計，不能用「擁有＝已讀＋未讀＋閱讀中」推算。對不上就停止寫入並回報；同步缺項不當成刪除或沒買。
- 只在內容有變動時寫入；每週存一份歷史快照。
- 安靜原則：只有登入失敗、逾時、總數對不上、有待確認重讀時才出聲。

## 不想接 API 的替代方案

手動整理一份清單（CSV 或 YAML：書名、作者、版本、進度、購買意願、載體／平台持有與來源時間），放到 `data_sources.manual_list`。敘脈者會在資料覆蓋中標示「手動清單，最後更新：<日期>」。
