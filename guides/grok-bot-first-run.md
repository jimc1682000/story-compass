# Grok Bot 首次設定流程（指引，未實測）

先試評，再 opt-in 連線，最後才 opt-in 排程；所有連線可略過，排程預設停用。Grok Share Template 未建立、未實測，沒有平台 adapter 隨套件提供。

## 1. 目標與少量已知作品

先用一句話目標、幾部已讀／已看作品與少量心得起步；可依 `templates/seed.yaml` 保存，也可只在對話回答。不要求 3–10 部才能過關，不要求先填預算或完整個人地圖。一次只問會改變判斷的一題。

資料不夠也可先一般分析，清楚標「個人依據不足／證據不足暫不評分」，不硬算個人增益分數。目標、已知作品都有時，即使全部平台未接也可個人化評估。

## 2. 試評一部

依 `skill/SKILL.md` 評估，說明只用哪些手動資料。影視分觀看建議、輕量取得方式、收藏價值；不能查到合法入口就標未知，不讓連線阻擋試評。

## 3. 選用連線

試評後才詢問是否接自己的倉庫、電子書平台的書櫃清單或影視紀錄工具的匯出。使用者明確選擇後，一次處理一個，先確認現有工具／匯出格式；沒有 adapter 就明說尚未實作，不假稱自動完成同步。首次驗證所選範圍、來源時間與總數，使用者看過才算該來源接好；不用等待全部來源。

格式與限制見 `guides/connect-github-repo.md`、`guides/connect-kobo.md`、`guides/connect-yamtrack.md`。不代登入、不改權限、不下單，不寫回已讀／已看狀態。

## 4. 選用排程

使用者另外要求才依 `guides/routines.md` 確認來源、頻率、時間、時區與輸出位置，單次試跑成功且使用者確認後才可啟用。套件只有停用設定與驗證規則，這次不建立或啟用任何任務。
