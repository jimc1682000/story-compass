# 連線指引：影視紀錄工具（唯讀；以 Yamtrack 為例）

| 項目 | 狀態 |
|---|---|
| 規則、狀態對應 | 已定義；本檔以自架的 Yamtrack 為例，其他影視紀錄工具的匯出可套同一組規則（本檔、`skill/references/status-mapping.md`；示意映射，**未用真實資料實測**） |
| 同步程式 | **本套件未附** |
| 用真實資料實測 | **未實測**（擁有者環境的資料來源目前為空，尚無真實資料驗證） |

## 原則（不可協商）

1. **唯讀**：從你自己的 Yamtrack **資料備份**（資料庫匯出或 Yamtrack 內建匯出檔）讀取；**絕不寫回** Yamtrack。
2. **不複製憑證或登入狀態**：不拿帳密、session、cookie。
3. **不部署、不升級、不維運 Yamtrack**；那是你自己的伺服器的事。
4. 安靜原則：只有來源讀不到或總數對不上才出聲；**連續失敗 2 次就暫停**，等你處理。

## 建議做法

1. 你在自己的主機上定期產生備份（Yamtrack 匯出 CSV，或資料庫備份）。
2. 把備份放到敘脈者讀得到的位置（`data_sources.watch_history_export`），**位置與主機名稱不要寫進公開檔案**。
3. 敘脈者只讀：作品、版本、媒體類型、季、集、進度、實際觀看／完成日期（來源有才讀）、你的評分與筆記（筆記可選擇不讀）。
4. 寫入知識地圖時，影視資料放在獨立的檔案或目錄，不混進書的擁有清單。分享套件的資料規範與範例已定義（見 `skill/references/cross-media.md`），真實 adapter **未實作、未實測**；不遷移既有私人資料。缺集數或觀看日期就留未知，不用同步日期替代。

## 對應

見 `skill/references/status-mapping.md` 的「影視狀態」。
